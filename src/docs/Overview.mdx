# Autonomy Widget

Mission status, time remaining, and the next available control in one compact surface.
This React implementation explores Skydio’s Rivit design language through live mission states, configurable controls, and browser interaction tests.

## Keep attention on the mission

The widget gives status and mission control a consistent home. Configuration selects the label, timer icon, and available actions; it does not add a different layout for every mission.

**Collapse for monitoring.** On a fine pointer at desktop widths, the resting widget is 240 × 48px. The expanded state is 88px tall and is available when the mission has additional controls.

**Expand for intervention.** The second row belongs to the current mission: waypoint actions, an orbit control, or an exit action while paused. The primary pause/resume control stays in the same position.

**Adapt to the viewport.** Below 600px, the compact surface prioritizes the timer and pause/resume control and removes the secondary row from the tab order. Coarse-pointer controls use 44px targets and a 60px first row. The breakpoint follows the browser viewport, not the parent container. Open Compact or resize Canvas to inspect this transition.

## The orbit reference stays put

<Canvas of={WidgetStories.OrbitMode} meta={WidgetStories} sourceState="none" withToolbar={false} story={{ autoplay: false }} />

The small blue marker stays at the center. The larger outlined indicator shows the current progress. Left and right carets move that indicator; they disable at the configured limits. This control is operated through buttons, not by dragging the track.

Orbit Mode is the manual example. Orbit Interaction runs the automated sequence, so an automatic test does not move the indicator when you open the manual story.

## What the demo proves

The examples exercise rendering, state ownership, command-intent callbacks, keyboard activation, named controls, tooltips, and timer behavior. Mission values and durations are demonstration data. The application supplies transport and command acknowledgment; no drone connection is represented.

The repository makes the boundary between UI behavior and the application’s command lifecycle explicit.
